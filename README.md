# Volkswagen

Навчальний статичний сайт Volkswagen з каталогом автомобілів, кошиком, конвертацією цін, кредитним калькулятором та інформацією про сервіс.

## Функціональність

- `index.html` — каталог автомобілів, перегляд фото, кошик і перемикач валют (USD, EUR, UAH, GBP).
- `credit.html` — кредитний калькулятор. Повзунки змінюють вартість авто, внесок, строк і ставку; сума кредиту, орієнтовний щомісячний платіж та переплата перераховуються автоматично.
- `servise.html` — інформаційна сторінка про сервісні послуги та контактний телефон.
- Спільні стилі розміщені в `index.css`; додаткові стилі сервісної сторінки — у `service.css`.

### Форми та заявки

Справжніх HTML-форм і серверного надсилання даних у проєкті немає. Кредитний калькулятор — це інтерактивні повзунки, а кнопка «Залишити заявку» лише повідомляє, що подання заявки ще не підключено. Контакт із сервісом можна ініціювати за посиланням на телефон.

## API курсів валют

Каталог запитує курси валют у JSON API Національного банку України. Якщо запит не вдається, сервер повертає помилковий HTTP-статус або відповідь не містить курсів USD, EUR і GBP, сайт використовує резервні значення: 1 USD = 40 UAH, 1 EUR = 43 UAH, 1 GBP = 50 UAH. Для такого режиму в панелі валют відображається попередження «НБУ недоступний — резервні курси», а подробиці помилки записуються в консоль браузера. Резервні значення орієнтовні й не є актуальними котируваннями НБУ.

## Кошик і зберігання після перезавантаження

Вміст кошика зберігається в `localStorage` браузера під ключем `volkswagen-cart-v1`. Тому товари, кількість і склад кошика відновлюються після перезавантаження сторінки в тому самому браузері та для того самого походження (origin). Коли кошик порожній, ключ видаляється. Оформлення замовлення є демонстраційним: показує локальне повідомлення, очищує кошик і не надсилає дані на сервер. Очищення даних сайту в браузері видалить збережений кошик.

## Запуск

Зовнішні залежності та збірка не потрібні. Для запуску локального HTTP-сервера відкрийте термінал у папці проєкту та виконайте:

```powershell
py -m http.server 8000
```

Якщо команда `py` недоступна, використайте `python -m http.server 8000`. Потім відкрийте [http://localhost:8000](http://localhost:8000). Для зупинки сервера натисніть `Ctrl+C`.

## Ручна перевірка

1. На головній сторінці змініть валюту, додайте автомобіль у кошик, змініть його кількість і перезавантажте сторінку — кошик має відновитися.
2. Перевірте видалення товару, спорожнення кошика та демонстраційне оформлення замовлення.
3. На сторінці кредиту змініть кожен повзунок і перевірте оновлення результатів. Кнопка заявки має пояснити, що надсилання ще не налаштоване.
4. За відсутності доступу до API курсів на головній сторінці мають з'явитися резервні курси та попередження.

Автоматизованого набору тестів у репозиторії немає.
